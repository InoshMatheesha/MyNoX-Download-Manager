# Roadmap

What's done, what's being built and what's planned for MyNoX Download Manager. Released changes
are in [CHANGELOG.md](CHANGELOG.md). Ideas and bug reports are welcome in
[Issues](https://github.com/InoshMatheesha/MyNoX-Download-Manager/issues).

✅ done · 🔄 being built · 📋 planned

## Version 1.0.1

- ✅ MyNoX Choice: a theme with its own layout (sidebar, header, action bar, list card, speed card)
- ✅ The browser extension added in one click from the app (Add it now)
- ✅ The portable copy as one .exe, updated by Update now; releases without zips

## Version 0.5.4

- ✅ MyNoX Download Manager for Windows 10 and 11: installer and portable copy
- ✅ The MyNoX logo in the app, the installer, the extension and its Download video button
- ✅ The browser extension in every release, with steps to add it to Chrome, Edge, Brave, Opera,
  Vivaldi and Firefox
- ✅ Help → Check for updates from this repository's releases
- ✅ The user guide (docs/) opened from the app's Help menu on GitHub

## Next

- 📋 Code-sign the installer and programs (fewer Windows SmartScreen warnings)
- 📋 The extension in the Chrome Web Store and on addons.mozilla.org, so browsers keep it up to date
- 📋 New screenshots for every help page
